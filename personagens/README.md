
# Personagens

Esta pasta é destinada ao armazenamento de arquivos relacionados aos lutadores do jogo, tais como:

- Scripts de comportamento individual (IA)
- Configurações de Sprites e Animações
- Dados de balanceamento (Stats)
- Componentes visuais específicos

Recomenda-se migrar definições como `BASE_CHARACTERS` (atualmente em constants.ts) para módulos dentro desta pasta à medida que o projeto cresce.
