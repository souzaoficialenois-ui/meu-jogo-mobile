# Pasta para o Logo do Jogo

Coloque o arquivo de imagem do logo do jogo aqui dentro!

### Instruções:
1. Faça o upload do arquivo de imagem do seu logo para este diretório.
2. Nomeie o arquivo como: **`logo do jogo.png`**
3. O jogo irá ler automaticamente este arquivo para exibir nas telas de início, criação de perfil e carregamento!

---

### Caminho Local:
* `/public/Assets/logo/logo do jogo.png` (carregado na aplicação como `/Assets/logo/logo do jogo.png`)
